# Rua Xe website FINAL

Dự án **Rua Xe website** hỗ trợ quản rửa xe và quản lý xe *một cách thuận tiện*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| `docs` | Tài liệu và hướng dẫn nhập hàng |
| `media` | Logo và hình ảnh của website |
| `data` | Bảng tính sản phẩm và đơn bán |
| `logs` | Nhật ký hệ thống và báo cáo |
| `backup` | Bản sao lưu logo |

## Lệnh kiểm tra dự án

```powershell
Get-ChildItem -Force
Get-ChildItem -Force -Recurse
```
